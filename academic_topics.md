# CSE3001 Advanced Topics
## Storage: magnetic disk, flash, RAID, file/record organization
## Indexing: ordered indexes, B+ tree, static hashing, dynamic hashing
## Query processing: query cost, cost-based optimization, heuristic optimization
## Transactions: ACID, isolation, serializability, locks, deadlocks, multiple granularity, timestamps
## Distributed transaction: two-phase commit
## Recovery: transaction/system/media failure, undo/redo, checkpoints, atomicity
These are explained in the report and viva sheet; the operational database demonstrates the applicable mechanisms with MySQL transactions and indexes.
